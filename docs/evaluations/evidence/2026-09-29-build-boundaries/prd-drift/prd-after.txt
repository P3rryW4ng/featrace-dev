Provide two independent local importers. Keep convert(text)->dict in upper.py and lower.py, without external effects.
T-UP CSV: upper.convert reads UTF-8 text with optional BOM using a header sku,name,price. Return {records:[], errors:[]}. Empty input returns empty lists. Header mismatch produces one {line:1,code:header} error. CSV quoted commas and multiline values must work. For data rows, line means one-based logical row (header=1). Strip all fields. Reject missing sku/name or extra/missing fields as invalid_row. Price must parse as a finite Decimal >=0 and at most two fractional digits, else invalid_price. Accept first occurrence of SKU; subsequent accepted SKU duplicates are duplicate_sku. Invalid rows do not reserve SKU. Accepted records contain sku,name,price with price formatted to exactly two decimals. Errors contain line and code. Preserve record and error order; no exceptions for malformed price.
T-LOW JSONL: lower.convert reads independent JSON lines; ignore blank lines but line numbers are physical one-based. Return {records:[],errors:[]}. Each object needs string nonempty id and timestamp, with timestamp an ISO8601 aware time (Z or numeric offset) and payload any JSON value. Invalid JSON -> invalid_json; nonobject or missing/wrong type fields -> invalid_event; naive/invalid timestamp -> invalid_timestamp. Normalize timestamp to UTC YYYY-MM-DDTHH:MM:SSZ (fixtures have no fractions). Accept first valid id; later duplicates duplicate_id; invalid events do not reserve IDs. Output records contain id,timestamp,payload; errors contain line,code. Preserve order. Empty input returns empty lists. No CSV dependency, global state or external effects.
