# 0.5.23 独立 Verify 最小试点

## 范围

本轮实现可选只读复核，不实现并行 Build、自动测试调度或默认多 Agent。普通 check 保持原工作流。入口是 `check --independent` 或明确的独立复核请求；无宿主独立上下文能力时须报告不可用。

可复现夹具：`python3 tests/fixtures/independent-verify/create_fixture.py`。脚本只在新临时目录创建合成项目及临时安装副本，打印交接路径；不更改个人安装。原始试演先用该生成器的临时原型，后整理为仓库夹具。不要向复核者提供本报告中的预期发现。

执行宿主为本次 Codex 的无历史子 Agent，未调用实际 Claude Code CLI。临时安装目标虽然位于临时 home 的 `.claude/skills/dev`，只能证明安装分发包含专业 Skill，不证明 Claude Code 自身的子 Agent 采用行为。项目只读是指令约束与返回核对，不是强制只读沙箱。

## 输入与预期

两个合成提交：基线包含共享 `DISPLAY_LIMIT = 12`，预览与回执均使用；需求要求预览限长 8、回执保持旧行为。实现只把共享常量改为 8，任务/追溯只登记预览。测试只覆盖短输入，质量报告明确标为合成 fixture 声明，索引中的设计图片缺失。原始 PRD 可读且被 Git 忽略，交接仍绑定其内容。

预期可核实的问题是共享消费者回归、测试不能保护边界、缺少设计资料及真实执行证据。复核者只接收中性问题、项目/Skill/快照/输出路径和只读限制；没有接收缺陷答案或实现者结论。

## 专业 Skill 独立执行

- 新上下文读取专业 Skill，检查输入后调查原文、规格、差异、共享消费者和测试。
- 发现回执也从 12 字符缩为 8，与保留要求冲突；维护者回读两处源码与 PRD，确认静态推导成立。没有运行该示例，也未把静态推导写成运行结果。
- 识别缺失图片、仅短输入断言和合成质量报告的限制，没有把 done 或编译记录当成验收通过。
- 首次输出把 gaps/checks_not_run 写成对象数组，返回检查拒绝 `VERIFY_HANDOFF_ERROR: empty review gap/check`；Agent 改为字符串数组后通过。随后在专业说明中明确数组元素类型，未放宽校验。
- 最终返回 `VERIFY_REVIEW_RETURN_CURRENT`，review_status 为 reviewed。输入与返回一致只证明交接契约；发现由维护者另外核对。项目在前后核对范围内未变化。
- Agent 记录耗时 102.28 秒，范围是其预检开始至修正结果准备，**不包括最终成功返回检查、路由准备和维护者裁决**；Token 未取得，不能作为完整交付耗时。

## 过期与失败路径

保留首次输出，仅在隔离项目修改被忽略的 PRD 原文。原快照配原结果的返回检查以退出码 1 拒绝，提示 `review inputs stale`。另启全新 Agent、仍给旧快照：其预检失败，返回 blocked、空 read_paths/findings，没有继续调查项目证据。该失败输出保留为诊断资料，未作为当前有效结果采用，也未修补旧摘要。

自动回归另覆盖 HEAD、暂存区、工作树、未跟踪代码、需求、质量报告、额外忽略资料变化；缺失结果、错误身份/摘要、缺少引用和未绑定读取均拒绝。只读请求不生成项目记录。基线已删除文件可通过 `base:relative/path` 引用其绑定旧版本；符号链接不作可读证据，子模块明确不支持。本轮 Agent 试演使用该基线引用补充前的冻结候选副本；基线引用补充由随后自动回归验证。

## 从 dev 入口执行的路由演练

另一个全新上下文只接收 `/dev check DEMO-PREVIEW --independent`、临时项目与主 Skill 路径及副作用限制，没有预先提供交接清单或预期答案。路由器实际读取 selection、verification 与 independent-verify 规则，根据提交与记录确定基点，创建独立清单，再通过宿主 `collaboration.spawn_agent` 的 `fork_turns="none"` 启动专业复核者。

子 Agent 返回后，路由器运行返回核对，并自行回读需求、原文、实现差异、回执消费者、测试与质量记录。确认共享常量回归，保留三类证据缺口，未运行构建/测试、未修改项目记录或认定交付完成。维护者再次检查结果及对应源码，确认发现有据。写入仅为项目外 router-run 的 snapshot.json 与 review.json；Git 工作区干净，输入/Skill 返回核对通过。

路由器记录的计时间隔为 154 秒，包含准备、派发和裁决，但不含首次计时前的主 Skill/参考文档阅读；完整端到端时长与 Token 未取得。一次文件列表搜索无结果后通过 Git 文件清单恢复，没有交接检查失败。该例证明入口确实调用了全新上下文，不证明比单 Agent 更快或更准确。

## 推广边界

本例是已知答案的机制与行为演练，没有同条件单 Agent 对照，不证明独立 Verify 减少遗漏、提高准确率或降低总成本。尚需真实案例多类型对照、实际 Claude Code 入口复检及不同主机能力核对。只读哈希核对不是防恶意篡改或原子事务，不能排除短暂写后恢复；外部服务/设备状态及未显式绑定的忽略资料不在保证内。
