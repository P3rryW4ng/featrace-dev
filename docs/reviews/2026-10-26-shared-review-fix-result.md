# 共享影响与独立评审：局部替换结果

2026-10-26。用户批准[评审方案](2026-10-26-shared-review-trigger-review.md)后实施。实现提交b9866f4；当前main候选，不是正式发布。正式和日常CC仍为0.26.1，未推送、发布或更新个人安装。

## 已替换的内容

- 删除shared类别自动强制独立评审的分支。shared仍表示实际共享传播；review.independent/reason/criteria另行表达由项目明确规则、严重风险或实质盲点决定的必要审查。没有新增风险分数、永久调用图或合同字段。
- validate_execution_plan/execution_ready负责运行需要的结构、输入、覆盖/时效、环境、缓存、约束、权限和局部未知；validate_acceptance_plan负责证明与评审选择，计划/判定/状态/结项仍核查它。run_check不再调用整份验收校验。协议继续沿真实执行调用采集，不增加名字豁免或任意旧哈希白名单。部分共同标准元数据仍保守参与执行校验，不承诺任意无害编辑都不失效。
- 独立评审仍绑定选定标准、实际事实、当前摘要及真实宿主出处；运行失败不能用改类别、取消独审或静态说明消除。现有省略review.criteria的旧计划保守全局含义保留，新计划要求指引显式选择范围。
- 共享调用、风险与自然语言项目规则的实际解释仍由Agent调查；内核结构通过不证明这些语义正确。不能把“可自评”当作通用低风险免测，更不能覆盖项目明确要求。
