# A109 整套替代实施合同

2026-10-22；用户在首批纵切后明确要求整套完成。此合同覆盖并取代A108“旧运行文件暂存、后续再裁剪”的限制。产品方向、历史测量不改写；当前源码实现与正式0.22.0分开。

## 已定范围

1. 物理退出旧需求台账、schema准备/存储展开、延续/采用、永久模块档案、历史回归同步、全量终审/报告绑定和重复路由。不是在新入口下隐藏旧代码。退出精确清单有旧读者候选、字节哈希、原保护替代；五项安装器用例从旧混合测试中提取，流式隐私检查和31项实测用例保留。旧 Git 版本可独立固定使用，新包不兼容或迁移其业务数据。
2. 活动任务内核：一份有上限的当前记录、逐项事实与判定、真实失败控制、按需独立评审、有界查询、截至此时的回执。原有需求变成新任务背景，不带入其全部原PRD验收。
3. 分离业务影响与执行输入。精确标准仍绑定相关路径，检查可包含目录/Git成员集合及明确外部工具链/依赖文件。瞬态计算，不持久化整仓清单；实际环境值只取摘要。真正改变执行输入才作废该检查；元数据/标准改字不强制重跑。远端或设备结果不可复用且限时有效。声明并不自动证明所有动态输入完整。
4. 项目级约束与保留策略：一份当前策略，原规则路径/摘要、适用范围/操作/环境及真实裁决引用；不替代宿主权限。局部可逆 test 操作复用既有授权，具体缺失才问。初始化只追加已知窄忽略块，未知策略/自定义块/已跟踪本地数据拒绝覆盖。
5. 清理接入开始/结项，而非只提供手工命令。按完成时确认的时区和自然日策略，默认建议7日；轮转有上限批次，避免活跃任务饿死后续到期项。保留未解决问题/限制及无法识别的原件；明确转交后可连任务记录一起忘记。截图等由attach登记所有权的副本也参与清理，原件不删；未登记文件不冒充可删除数据。维护锁与64任务槽分离，防止锁碰撞造成永久滞留。无个人定时器、业务历史删除或 Git 重写。
6. 当前代码查询而非永久手写项目地图。文件候选与字面代码搜索、单项评审输入和分页详情；默认输出16KiB上限，长内容可继续读取，预览不假称完整。没有完整动态语义图承诺。
7. 完整交付：源入口、Android选择指导、安装说明、产品/架构/接续文档和测试同步。发布/推送/日常安装须另有实际授权，本轮不执行。

## 数据和保护

运行包10文件：SKILL、宿主元信息、任务/输入/策略/隐私4脚本、任务/约束/隐私3引用、Android指南。单一`.featrace-policy.json`+可清理`.featrace`数据。上限是工程保护值，不是实测最优阈值；资源耗尽明确拒绝，不截断成通过。

实际失败、源码漂移、证据损坏、缺授权或未解决影响均不能通过改名/分类绕过。静态无影响不要求运行时证明未改的逻辑，也不能冲掉真实运行失败。评审只看其变化/未知主张及共同影响分析，不重复全量深入审查。独立宿主出处真伪和依赖语义完整性仍需Agent/人调查，不由JSON验证器担保。

语义标准变化影响相应判定，不使不相关物理执行失效。完成回执是as-of，不在未来每次提交时重新打开。重要永久事实用测试、相邻注释或项目现有精简记录表达；不永久保存每个任务全过程。

## 退出安全

批量白名单删除曾被自动审批拒绝，未执行；随后完成173个精确文件的读者/哈希/替代保护清单，先备份并逐字节验证所有当前内容（含未提交旧候选），再以同一清单删除，批准通过。业务项目、日常安装和Git历史未动。旧测试文件原含705个方法，5项安装保护提取保留，其余700针对已退出合同，不再维护。它们不与新系统的必要覆盖等价；流式隐私用例继续运行。

历史文档的退役源码链接固定到旧提交，不假装旧文件仍在运行；旧测试结果保留其原输入身份，不能套给当前源码。当前完整测试是当前受支持功能的完整套件，不宣称与旧功能兼容。

## 验证与完成判定

局部UI/共享/交互分类，外部工具链/成员变动，远端缓存失效，输入漂移/负向/超时/快输出/已关闭stdout，真假评审、分页尾部、私密输出、策略冲突与范围、原生工具回退、7日清理/限制交接、安装所有权和双宿主目录CLI均需覆盖。

先完成边界审计/专项，再冻结一次完整当前回归；真实设备/业务不为维护重跑。完成实现不等于第二阶段达标：自然Agent是否正确分类、跨真实上下文接续、净耗时/成本和误阻塞/漏验需真实试点，必须单独报告。POSIX、非分布式锁、声明式外部环境、有限文件/输出上限是当前支持边界，不是待开发功能伪装。

最终核查补充：主张可声明sources绑定真实产品资料；该语义变化只作废相应判定。原始手工观察按行为输入而非验收措辞绑定，原时间/目标/事实ID保留；静态无影响不能因标准改为changed而变成运行证据，真实失败始终阻塞。

审核后修正采用[A110边界](../decisions/architecture.md#a110审核后的状态与范围边界修正)：本次scope与外部分支提示分离、局部未知/授权调查、独立失败状态、操作权限/环境校验、安装身份和只读存储统计；本页早先128项是当时截点，最新输入及结果以验证入口为准。
