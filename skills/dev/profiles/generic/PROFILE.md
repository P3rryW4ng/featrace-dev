# Generic adapter

Supports evidence-based planning for other languages without pretending to have platform-specific automation. Read manifests, build scripts and CI to identify stack, modules and commands. Package.swift can be a library, package.json can be a service, and Gradle can be JVM-only; do not classify by filename alone.

Inspect representative source/tests to record architecture, conventions and reuse candidates. Fill baseline/quality-gates.json with argument arrays and project-relative working directories. Only use commands established by project evidence or an explicit user choice. Missing commands remain unconfigured and block claims of verified completion.

For iOS, Web and backend work use this profile until dedicated tested adapters exist. Figma is unnecessary for headless work; API contracts are unnecessary for local-only computation. Record applicability from scope, not platform name.
